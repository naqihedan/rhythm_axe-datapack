# 谱面格式校验

> 自动化的格式校验尚未实现（规划见待做清单）。本文档先列出 **error 级规则**——违反这些规则，谱面连基本运行都做不到（或运行中必然出错）。这些规则同时是未来自动校验的实现依据；当前由谱师对照[谱面编写规范](谱面编写规范.md#谱面编写规范)自查。

## 错误 error（影响基本运行）

### 可以被自动检测到的错误

- 未定义 `end_time`
  谱面没有结束点，主循环无法正常结束

- 没有 `timing_points`
  无法确定初始 tick rate，谱面节奏无法启动

- 结束点之后仍有音符/事件（`time > end_time`）
  这些物件永远不会被处理，游戏结束时还留在场上

- 音符缺必填字段（`id` / `type` / `time`），或 `type` 超出 0~4
  生成或判定无法匹配

- `notes` / `timing_points` / `events` 未按 `time` 升序
  游标推进失效，物件错乱

- 音符/事件/时间点 `time < 0`
  位于时间轴之外，永远不会被处理

- 混凝土/染色玻璃 `color` 超出 1~16
  颜色映射失败，显示异常

- `size` / `note_base_life` / `duration` / `density` 越界（低于各自最小值）
  生成异常（如 0 大小、负寿命）

- `teleport=true` 但 `spawn_pos` 未设置
  玩家被传送到无效位置

- 同一刻（相同 `time`）存在 2 个时间点或 2 个事件点
  规则：一刻内至多 1 个时间点、1 个事件点（二者可共存），但同一刻不能重复；重复会导致游标推进/判定引用歧义

### 不能被自动检测到的错误

- 谱面根数据缺失/损坏（缺 `notes` / `timing_points` / `events` 数组，或字段类型错误）
  读取阶段即失败，无法开始游戏

- 引用不存在的资源（`music` / `preview` 音效、`hit_events` / `events` 里的命令或 function 不存在）
  宏执行时报错，反馈/事件失效

- 同一游戏刻内两个判定距离过远、无法同时判定的音符
  其中一个必然无法判定（见[谱面编写规范](谱面编写规范.md#谱面编写规范)）
