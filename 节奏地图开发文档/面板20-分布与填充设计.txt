  ────────────────────────────────────────────────────────────────

                       按钮上显示当前名称，点击即切下一个（沿用现有编号顺序 123）
  幂次（行 3 / 行 7）  1~5（1 = 线性），[-] / [+] 到边界时变灰不可点

  【使用首尾音符时间】 起 ← 选区最早音符 time；止 ← 选区最晚音符 time

  ★ 灰态联动          模式「固定个数」⇒ **行 13（间隔）整行灰 + 不可点**，
                        hover「固定个数模式下不可用」；
                      模式「固定间隔」⇒ **行 12（个数）整行灰 + 不可点**，
                        hover「固定间隔模式下不可用」。
                      模式按钮本身始终可点。
  个数（行 12）        1~99；[-] / [+]（±1）到边界变灰
  间隔（行 13）        1~9999 刻；**三级 ± 按拍长**，到边界变灰

                         [--]  / [++]  = 半拍 = tpb ÷ 2（向下取整，最少 1）

                       tpb 取法与面板 11「判定时间 ±tpb」一致：调用 `note_time_tpb` → `#time_step`
  开关（行 15/16）     行 15 允许一刻内填充多个音符：禁止 / 允许（默认禁止）

  执行（行 18）        【执行分布】/【执行填充】共用上面同一套参数：
                       分布 = 把已有选中音符按参数重排；
                       填充 = 先按参数生成新音符，再对它们做同一次分布。
                       三色区分：【执行分布】绿 /【执行填充】金 /【返回】暗蓝

 四、参数存储（maps.editor.editing.df）
================================================================

 editing.df = {
     from: 10,                          // 来源面板（10 / 18），【返回】用
     t_ease: 1,                         // 时间缓动 1缓入/2缓出/3缓入缓出
     t_pow: 1,                          // 时间幂次 1~5（1 = 线性）
     t_a: 0, t_b: 256,                  // 时间端点：起 / 止（刻）
     s_ease: 1, s_pow: 1,               // 空间缓动 / 幂次（同语义）
     s_a: [0.0d, 0.0d, 0.0d],           // 空间端点「从」（XYZ 世界坐标）
     s_b: [0.0d, 0.0d, 0.0d],           // 空间端点「到」
     dup: 0b,                           // 0 = 禁止同刻（自动错开 1 刻）；1 = 允许
     dfsel: 0b,                         // 0 = 不改选区；1 = 操作后选中结果
     fill_mode: 0b,                     // 0 = 固定个数；1 = 固定间隔
     fill_count: 3,                     // 每段插入个数（1~99）
     fill_step: 4                       // 每段间隔（刻，1~9999）
 }

 说明：t_ease / s_ease 与音符 `anim_easing` 同语义（1 缓入 / 2 缓出 / 3 缓入缓出）；
       t_pow / s_pow 与 `anim_power` 同语义（1~5，1 = 线性）。
       循环顺序即 1→2→3（= 缓入→缓出→缓入缓出），与现有面板 11 编号一致。

 六、注意事项
================================================================

 1. 分两步落地：
    ① 先只写**纯 tellraw**（无 click_event、无灰态切换、无数值联动），你调排版与文案；
    ② 排版确认后再补 click_event / 灰态 / 数值刷新 / trigger 分发。
    写②时严格遵守开头的「组件继承铁律」（每行中性根 + 可点元素自带完整样式）。
 2. 缓动方向语义：类型 1（缓入，E(u)=u^p）在分布里是「靠 起 端更密」，类型 2（缓出）反之；
    类型 3（缓入缓出）两端密中间疏。**此项待游戏内实测确认后写进文档。**
    另注：反转折入/缓出只能翻转密度方向，**不能**替代「从/到 互换」（后者会反转路径方向），
    但自动填端点时方向本就正确，故无需该按钮。
 3. 规模上限：填充总数 ≤ 1000，超过直接报错退出（防撞 maxCommandChainLength）。
 4. 跨刻：涉及音符数 > 50 时，分布 / 填充走 `_next` 模式分刻执行。
 5. 收尾次序：file/begin → 计算并写入 → move_out/in 重排 → commit →
    下一刻再 refresh + 回面板（避免同链渲染被截断）。
 6. 精度：判定位置 ×100 定点运算，写回 double 0.01；time 取整到刻。
 7. 同刻修正：E 单调 ⇒ 结果天然保序；dup=禁止时只需
    `if t_i' <= t_{i-1}' then t_i' = t_{i-1}' + 1`（O(k)）。
 8. 校验：起点 < 终点、从 ≠ 到，否则【执行分布】变灰（hover 说明原因）。
 9. 分布会改判定位置 ⇒ 选区锚点由 sel_rebuild 自动跟随，无需特殊处理。
