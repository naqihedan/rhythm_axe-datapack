# 刻度生成规则

> 由 `tick.mcfunction` 定义，每个 tick 位置按顺序执行以下放置操作。
> 后放置的会覆盖先放置的。

---

## 一、轨道框架

| 说明 | 方块 | 位置 |
|---|---|---|
| 轨道外缘（换行检测用） | `black_terracotta` | `~4 ~-1 ~` 和 `~-4 ~-1 ~` |

---

## 二、底面（y=-1）

### 2.1 小节底色（宽7格：~-3 到 ~3）

| 颜色组 | 颜色号 | 方块 |
|---|---|---|
| 0 | 0 | `light_blue_terracotta` |
| 0 | 1 | `yellow_terracotta` |
| 1 | 0 | `blue_terracotta` |
| 1 | 1 | `orange_terracotta` |

> 颜色组每小节翻转一次（`color_group %= 2`），颜色号每拍翻转一次（`color_group_number %= 2`）。

### 2.2 刻度背景

| 方块 | 宽度 |
|---|---|
| `white_terracotta` | ~2 到 ~-2（宽5格） |

### 2.3 分段刻度线

> 规则：检测 `tick_per_beat` 能否被 N 整除 → 若能，`step = tpb/N`，在 `tick % step == 1` 处放置。

| 分段 | 方块 | 宽度 | tick 范围 |
|---|---|---|---|
| ~~16段~~ | *已移除* | | |
| 12段 | `light_gray_terracotta` | 1格 (`setblock`) | ≥24 |
| 9段 | `light_gray_terracotta` | 1格 (`setblock`) | ≥18 |
| 8段 | `yellow_terracotta` | 1格 (`setblock`) | 16~23 |
| 8段 | `yellow_terracotta` | 1格 (`setblock`) | ≥25 |
| 6段 | `purple_terracotta` | 1格 (`setblock`) | 12~17 |
| 6段 | `purple_terracotta` | 1格 (`setblock`) | ≥19 |

| 3段 | `magenta_terracotta` | 1格 (`setblock`) | 12~23 |

| 2段 | `red_terracotta` | 3格 (`fill ~1 ~-1 ~ ~-1 ~-1 ~`) | ≥25 |

### 2.4 起始刻度（每拍首tick）

| 条件 | 方块 | 宽度 |
|---|---|---|
| tick_per_beat ≥ 12，小节开头 | `black_terracotta` | 5格 (`~2` ~ `~-2`) |
| tick_per_beat ≥ 12，非小节开头 | `black_terracotta` | 3格 (`~1` ~ `~-1`) |
