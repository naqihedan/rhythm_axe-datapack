# 点赞特效（goodfx）— 字面量架构（2026-10-11 重构）

一组「👍 拇指手势 + 一圈放射光」的展示实体特效。**所有数值全部写死成字面量**（由
`scripts/gen_goodfx_waves.py` 用固定种子生成），运行时**零数学、零每刻全量写**，只靠
展示实体的客户端插值跑动画。

## 五个入口

| # | 函数 | 干什么 |
|---|---|---|
| ① | `function …/goodfx/gen` | 生成一组静态（满大小、默认中心 `-4.25 1.625 0.5` = 拇指视觉中心） |
| ② | `…/goodfx/anim` | 给 ① 的静态组播 16 刻整组动画 |
| ③ | `…/goodfx/spawn` | 生成一组「伪随机」组并播动画（`{pick:1..21}` 指定第几组，不写=1） |
| ④ | `…/goodfx/repeat` | 一次生成 n 组（`{n:1..21}`，不写=1），组间错开 1 刻 |
| ⑤ | `…/goodfx/total` | 4 波（0/32/64/96 刻）× 3/5/8/13 组，256 刻清场 |

## 动画时序（四段线性，客户端插值实现）

| 刻 | 事件 |
|---|---|
| 0 | 出生（缩放 0，不可见） |
| 1 | 目标：缩放 1、旋转 15°（duration 6）→ 段1 线性 0→1 / 0→15° |
| 7 | 目标：缩放 1、旋转 45°（duration 6）→ 段2 缩放不变 / 15→45° |
| 13 | 目标：缩放 0、旋转 60°（duration 3）→ 段3 线性 1→0 / 45→60° |
| 16 | kill（段4 不可见保持）⇒ 寿命正好 16 刻 |

## 性能设计（为什么不再卡）

- **波内一次性冒出**（用户 2026-10-12 指定）：整波 n 组同刻直接调用 ⇒ 该刻一次性
  summon n×14 个实体，**会有一根 mspt 尖峰**（波5 ≈ 294 个）。想改回错峰：生成器
  `WAVE_SPREAD` 设 ≥1 重跑。
- **关键帧只在 1/7/13 刻各写一次**（每组 14 条 data merge），其余全靠客户端插值 ⇒
  没有「每刻 × 每实体」的 NBT 写风暴（平均 mspt 低）。
- 组 = 14 实体（6 手势 + 8 射线）。**每波有自己的专属元件** `w<w>g<slot>`（大小基准随波递减：
  100/85/70/55% ±20pp，位置取 `WAVE_IDX` 子集）；共用池 `g1..g21`（50~100%）只供 ③`spawn`
  与 ④`repeat` 取用。波/③/④ 互不撞 tag（寿命 16 刻 < 波间隔 32 刻）。

## 想改数值改哪里

| 想改什么 | 改哪 |
|---|---|
| 每波组数 / 波间隔 | `scripts/gen_goodfx_waves.py` 的 `WAVES` + `total.mcfunction` 的 schedule |
| 动画分段（刻/时长/角度/缩放） | 同脚本 `SEG` / `KILL_K` |
| 「伪随机」的值（位置/朝向/大小） | 同脚本 `POSITIONS`（21 个手调散点，范围 x∈[-5.5,1.5]、y∈[0.5,2.5]、避开中心禁区）/ `SEED`（朝向与大小） |
| 手势造型 / 射线数量 / 组中心 | 同脚本 `GEST` / `RAY_N` / `RAY_R` / `CENTER` |
| 改完 | 重跑 `py scripts/gen_goodfx_waves.py`（会整体重写 `waves/` 目录） |

## 注意

- `waves/` 目录 158 个文件**全部由脚本生成**，手改会被下次重跑覆盖。
- ② 只对「① 刚生成的静态组」有效（按 `goodfx_static` tag 操作）；③④ 的组各自带
  `goodfx_g*` tag，互不干扰。
- 清场：`cleanup`（256 刻自动）= kill 全部 `goodfx` + 删计分项 `gfx` + 删 storage 键。
