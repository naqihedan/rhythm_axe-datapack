# 编辑器

## 介绍

- 用一个function命令作为入口打开编辑器并且指定一个作为要修改的谱面。
- 编辑器会读取谱面的内容，在编辑区域生成时间轴和音符、事件，让谱面内容可视化、可编辑化。
- 在游戏世界里根据当前谱面内容，完整重现谱面游玩时的状态
- 与游玩模式一样会用bossbar显示当前播放进度
- 使用[**伴侣mod**](工具组件.md#工具组件)让谱面的内容更加易于编辑，主要包括音频的播放控件系统
- 定义所有操作，使所有操作可逆
- 错误检测系统，对谱面的问题操作进行警告和报错（自动谱面格式校验规划中，暂未实现）

> 当一个玩家处于谱面编辑状态，那么它将不被允许开始游戏，聊天栏提示将要和他一起开始游戏的所有玩家“{player}正处于谱面编辑状态，无法开始游戏”
> 当进入编辑器，玩家会根据谱面的传送开关与否来决定是否传送到谱面位置
> 当重进存档（每次运行load）
>
> - 如果编辑器仍处于打开状态：【编辑器】 编辑器未关闭
> - 如果不仅处于打开状态而且还有没保存的内容：【编辑器】 编辑器未关闭且有未保存的内容
>

## 数据结构与状态

编辑器的运行时状态、计分板镜像、宏参数通道、撤销历史与剪贴板的具体结构与键名，见
**[编辑器实现 - 数据结构与状态](编辑器实现.md#数据结构与状态)**。

使用者只需要知道下面这几条：

- **单人锁**：编辑器同一时间只允许一个玩家使用。别人正在编辑时尝试打开会提示「编辑器已被占用」；自己已在编辑再打开会提示「您已经进入编辑状态了」。
- **改动不立即落盘**：编辑中的一切操作只改「工作副本」，**只有点【保存谱面】才真正写入谱面**。所以改错了可以一路撤销，退出时也会先问要不要保存。
- **撤销/重做有多级**：上限由**全局设置里的「编辑器历史条数」**决定（默认 50），超出后最旧的记录被丢弃；**保存不影响撤销**（保存后仍能撤销回到更早状态）。
- **撤销后做新操作 = 走岔路**：被撤销掉的「重做」记录会全部丢弃，不能再重做回去。
- **剪贴板按面板各自独立**（时间点 / 事件指令 / 音符 / 击打事件 / 多选音符互不覆盖），**只在退出编辑器时清空** —— 翻页、切换面板、返回菜单都不会丢。

## 编辑器可进行的操作

### 时间控件

- 播放/暂停：点一下播放，再点一下暂停；**只要存在「记录点」**，每次暂停（播放→暂停）都会跳回记录点（记录点**持久**，可反复用，不随暂停/播放清除），并在聊天栏提示「已经返回到记录点 xxx，在记录点处蹲下右键可以清除记录点」
  - **蹲下右键**（仅播放/暂停工具）= 记录点开关，**只操作记录点、不控制播放/暂停**：播放头**正停在记录点上**（且已存在）→ 删除；否则 → 把当前播放头记为记录点（覆盖旧值）并发一行提示。
- 快进/快退： 以刻、拍、小节、为单位更改播放事件
- 播放速度调整：一个按钮，点一下在25%/50%/75%/100%四个播放速度之间切换；**下蹲使用**播放速度工具则切换为**音符流速工具**，在 2/4/8/16 流速间循环
- 节拍器：开关，开启时会在每拍播放节拍器声音；在每小节开头和时间点处会播放另一个节拍器声音

> **方向工具的自动改名**：前进类工具（前进一刻/一拍/一小节）站立时显示【前进XX】，蹲下时自动改为【快退XX】；快退类工具（快退一刻/一拍/一小节）站立时显示【快退XX】，蹲下时自动改为【快进XX】，并相应切换提示文本（"蹲下以快退" ↔ "站立以快进"，快退类为"蹲下以快进" ↔ "站立以快退"）。切换是自动的，不用手动管。

> 此处操作没有撤销重做反馈信息

**播放时的 tick 流速**

| 时机 | tick rate | 音乐 |
| --- | --- | --- |
| 开始播放 | `tick rate <bpm>bpm <tpb>`（当前播放头所在红线的速度），播放经过红线时更新 | `/playmusic` 从播放头起播 |
| 暂停 / 播到尾自动暂停 | `tick rate 20` | 暂停试听音乐 |
| **播放中退出编辑器** | `tick rate 20` | 同时停掉试听音乐 |

- 编辑器为单人设计，不考虑 tick 速度变化对世界的其他影响

> 使用mod实现**音频的随机访问播放**，不再依赖外部软件

## 谱面实时预览

1. **数据源 = 工作副本 + 播放头**

    - 世界展示的内容来自当前工作副本快照，每次更新后世界中的音符也随之变化
    - 播放/暂停/拖动时，世界中的物件呈现对应的时刻状态

2. **世界重现的对象**
- **活跃音符**：按谱面里的音符在世界上生成与游玩一致的实体，类型/颜色/大小/缓动/长条拉伸都按谱面字段；随播放头推进走完 出生→移动→到达判定位置→消失 的完整生命周期
- **音符事件**：击打粒子/音效在**判定命中时按实际判定等级**播放（自动预览模式 = 寿命 0 时按 `perfect` 播）；音符没单独设击打音效/粒子时用全局设置。染色玻璃的伤害反馈不播放
音符**开始移动那一刻**与**之后每一刻**是否执行对应情况指令
    - 所有音符在退出编辑器后清理

3. **默认带【游玩测试】**（见下《真实判定模式》）
    - 默认（开）试听时音符会在判定窗内等玩家输入：命中才播音符事件、超窗 miss；关掉则回到旧行为——不判定、到判定时刻自动按 `perfect` 播

4. **编辑后世界会即时更新**
    - 放置 / 删除 / 改属性后只更新涉及的那个音符，不整体重建
    - ⚠️ **时间点 / 事件点的增删改都不会让音符重建**（它们不改音符数据）—— 谱面大时这一步原本明显卡顿，现已省掉
    - 时间轴（mod 界面上的条）与这个刷新无关，编辑后总会同步

> 出生顺序、增量更新的实现细节见 [编辑器实现 - 谱面实时预览](编辑器实现.md#谱面实时预览实现)。

### 真实判定模式

> 开关：**主菜单行 105 的【游玩测试：开/关】（`10502`）**，与节拍器同行。**默认开着**。
> 目的：让谱师在编辑器里**照着真实游玩的手感试打**——有判定、有反馈，但**不计成绩与连击**。

| 开关 | 试听行为 |
| --- | --- |
| **开**（默认） | 音符在判定窗内等输入：命中 → 按等级播音符事件；超窗 → miss（木板静默清除） |
| **关** | 不判定，到判定时刻按 `perfect` 直接播音符事件（等同 auto）。到判定时刻还会**自检音符盒/木板是否埋在方块里** → 命中则在聊天栏报错「音符位于方块中：id：…，time：…，x/y/z：…」，只提示、不影响播放 |

**判定输入（照搬游玩语义）**

| 类型 | 输入 | 判定窗 |
| --- | --- | --- |
| 0 音符盒 | **看向**（视线命中） | `[3x, -2x]`，命中按当前寿命查档 |
| 1 木板 | **看向** | **`[2x, -2x]`**（无 bad 段：`[2x+1,3x]` 内看着也不判），命中**恒大 P** |
| 2 唱片机 | **左/右键点击**音符 | `[3x, -2x]` 按点击时刻寿命查档；**life == -2x 仍未点击 → 看向则 good_late，不看则 miss** |
| 3 混凝土 | **站位判定**：段内任意刻玩家在判定区域 → 该段大P；段末不在区域 → 该段 miss | — |
| 4 染色玻璃 | 碰撞扣血的**反馈部分**（不扣血、不计成绩）—— ⏳ 待实现 | — |

**窗口与等级**：与游玩**同一套边界**（`x` = 当前时间点设定的「判定缩放倍数」）

| life = 音符判定时间 − 播放头 | 等级 |
| --- | --- |
| `[2x+1, 3x]` | bad |
| `[x+1, 2x]` / `[1, x]` | good_early / perfect_early |
| `0` | perfect |
| `[-x, -1]` / `[-2x, -x-1]` | perfect_late / good_late |
| `< -2x` | miss |

- **木板特例**：命中**恒大 P**（无 bad 段）；未抵达判定位置（`life ≥ 1`）被注视**只记录、不当场判**，抵达判定位置及之后（`life ≤ 0`）有记录或此刻被注视才判；超窗**静默清除**（无 miss 反馈）
- **判定保护**（**只有音符盒**；木板天然是「先记录、后结算」，不需要保护状态）：
  - **进入**（只置状态，**不判定**）：`life == 3x+1` 且本刻**视线经过判定位置**（完美判定区域）
  - **记录**（保护期 `[3x,0]`，**暂不判定**）：「看着」= 视线与**音符**相交 **或** 视线在**完美判定区域**内 → 记录当刻寿命；结算时的「看着」同口径
    > 后者对应「直到取得大P准星一直在完美判定区域 ⇒ 大P」这种情况：**音符还没到判定位置时**它还在飞行，**只认“命中音符”会让这种打法一条记录都没有** → 全程盯着判定位置反而拿 PL
  - **结算**（`life == 0`）：有记录且当前看着 → 大P；有记录没看着 → 按记录寿命；无记录但看着 → 大P
  - ⚠ **进入保护 ≠ 保证大P**：保护期内从未与**音符**相交 ⇒ 无记录 ⇒ **等同无保护**（退回“相交那一刻的寿命”判：`life < 0` 时看音符仍可拿 perfectL / goodL）；始终不相交才由出窗收尾（miss）
- **混凝土（type 3）**：逐刻按寿命算「待判段」，**每刻最多推进一段** ⇒ 天然抵抗快进/拖进度条跳段；漏判兜底：寿命低于本段下界时每刻静默推进一段（不补播反馈）
  - **seek 的取舍**：快进/快退/刷新重建时，**段进度会按播放头预置**（播放头之前的段视为已判过），所以不会出现"一播放就从第 1 段连续补判"；但**保护期的记录不预置** —— 记录窗口只有判定的前 `1~3x` 刻，播放头越过它之后就再没机会记录 ⇒ 此时段末不在区域内按 **miss** 收尾。这是有意为之：seek 之后"当时到底站没站"已无从得知，不编造记录；重建后只要在段末站进区域，照样判大 Perfect

- **同一刻判定限制**（规则表见 `音符.md`；游玩与编辑器试玩一致）：
  - 同一刻有多个普通音符时，**只判定最靠前的那个**（`time` 相同的整批放行）
  - 被压制的候选本刻**不判、不惩罚**（下刻寿命 −1 后重新参与，若因此越过窗口则照常 miss）
  - **保护中的音符不算候选、不占名额**，其 `life == 0` 的结算不受此限制（结算时刻固定，推迟就破坏保护语义）

**反馈**

| 项 | 说明 |
| --- | --- |
| 音效/粒子 | 按**实际等级**播放（不再是固定 `perfect`）；miss 用 miss 情况 |
| 击打事件 | 判定时按**实际等级**执行对应那一条；其中「生成时」（音符开始移动那一刻）只执行一次，「每刻」在音符存活期间每刻执行。受主菜单【事件播放】控制 |
| 文字 | actionbar / 聊天栏，受【音符hotbar反馈】/【音符聊天反馈】控制（与游玩共用这对全局设置）；actionbar 含虚拟血量与连击，聊天栏不含 |
| 成绩 | **完全不记**（不计分、不计连击、不写最高分，与游玩计分完全隔离） |

**边界**

| 场景 | 行为 |
| --- | --- |
| 暂停 | 时间冻结 → 不判定；**并把「已过判定位置、尚未判定」的音符静默清除**（否则会一直挂在判定位置上） |
| seek / 快进快退 / 跳转 | **保持旧行为**（自动按 perfect 播 + 橙光提示），不判定 |
| 播放速度 25~100% | 判定窗按谱面刻计算，随 `tick rate` 缩放，自动一致 |
| 播放中切开关 | 立即重建音符，窗口随之变化 |
| 点击冲突 | 播放中 + 判定模式下，左/右键**不再**选中音符，转为判定输入（暂停后恢复正常编辑操作） |
| 进度显示 | 播放中**不再**每刻刷 actionbar 进度（会把判定文字顶掉）；进度改看 bossbar 与主菜单「当前刻/最终刻」；快进/快退/回到开头保留一次性提示 |

> 判定链路的函数分工、射线步进参数、命中标记传递方式见 [编辑器实现 - 真实判定模式](编辑器实现.md#真实判定模式实现)。

### 引导线

连接相邻 0/1/2 音符的青色玻璃条，提示音符间位置关系。

**触发条件**：每个开启了引导线的 0/1/2 音符 A 都会生成一条连向它**之后的下一个 0/1/2 音符 B** 的引导线（B 是否开启不影响）；**混凝土/玻璃不生成引导线且会被跳过**（A 连向其后第一个普通音符）；A 未开启则不生成（即使 B 开启，A 与 B 之间也不连）。

**外观与收缩**（设 n = B 判定时刻 − A 判定时刻，m = 播放头 − A 判定时刻）：

1. **A 出生 → B 出生**：A 出生时引导线显示。A 端用 A 的实时视觉中心，B 端连 **B 的出生点**（判定位置 + 起始位置）
2. **B 出生 → B 判定**：A、B 都在，两端都用实时视觉中心
3. **A 已判定**（`0 ≤ m < n`）：A 端固定为 A 的判定位置，长度按 `L = l × (n−m)/n` 收缩，**B 端锚定**；`m ≥ n` 时引导线消失

> 其中 l 在「A 还没判定」时取 A、B 两个音符视觉中心的距离；在「A 已判定」时取「B 的视觉中心 到 A 判定位置」的距离。
>

### 谱面操作

- 新建：需要mapid
- 打开：需要mapid
- 保存
- 另存为新谱面：把当前工作副本复制成一张新谱面（id = 原名 + `_copy`）并切换到它来编辑；**新谱面不会自动保存**，需要再点【保存谱面】才真正写进去 —— 与新建未保存谱面一致。切换之前会问要不要保存当前谱面的内容

- 若**不存在** → 以默认模板新建一张**编辑工作副本**（只是暂存，**谱面本身还没有被创建**）：
    1. 写入默认基本信息（谱面 id、初始血量 10、最大人数 1 等）
    2. 三个内容数组都初始化为空（音符 / 时间点 / 事件）
    3. 自动追加 `time=0` 的初始时间点（默认 150 BPM、4/4 拍、8 tpb）
    4. 出生点默认为玩家当前位置，出生朝向默认 0
    5. 打开编辑器界面

**编辑状态下再次执行 editor 命令**（切换谱面）：

- 目标 mapid **与当前编辑谱面相同** → 提示“您已经在编辑这张谱面了【返回编辑器】”，不切换
- 目标 mapid **不同** → 弹出**切换谱面确认**面板，显示“您当前正在编辑 {标题}-{曲师}-{谱面作者}（mapid:{mapid}）”，按是否有未保存内容给按钮：
  - **有未保存内容**：【保存当前谱面并开始编辑新谱面】/【丢弃当前谱面改动并且开始编辑新谱面】/【继续编辑当前谱面】
  - **无未保存内容**：【编辑新谱面】/【继续编辑当前谱面】
- 切换 = 清空当前编辑状态后重新加载目标谱面
- 【继续编辑当前谱面】回到进入切换确认前的面板

> 只有执行**保存**操作才会把工作副本真正写进谱面；新建的谱面退出前不会自动保存，需手动点保存。

**修改谱面id**：以新 id 创建一张新谱面 → 复制原谱面的全部内容 → 清掉旧 id 留下的数据 → 删除原谱面。历史记录不受影响。

**保存**：把editor内容写入mapid

**退出**：

- 没有未保存内容：直接退出，清空状态
- 有未保存内容：退出之前提示是否要保存内容

**导入音频**：往资源包里添加音频文件，并在音效配置里定义

#### 改 tpb 的同步缩放（面板 4 行 107，★ 2026-10-29）

改 `tpb` 会改变「1 刻」的现实时长：$\text{每刻毫秒} = \dfrac{60000}{bpm \times tpb}$。所以把 8tpb 改成 12tpb 后，同样的刻数只占 2/3 的时间，**谱面整体相对音乐提前**。这一行的开关就是为此提供自动换算。

**换算因子**（不是写死的 1.5）：

$$\text{ratio} = \frac{tps_{新}}{tps_{旧}} = \frac{bpm_{新}\times tpb_{新}}{bpm_{旧}\times tpb_{旧}}$$

- 只改 tpb 8→12、bpm 不变 ⇒ ratio = 1.5。
- **只改 bpm 不触发**（有意改节奏映射，补偿会误伤整段）；改拍号 / 判定缩放倍数也不触发。
- 触发条件：`tpb_旧 ≠ tpb_新`（且至少开一个开关）。

**映射规则**（设被改的时间点为 $P$，下一个为 $N$，$A = P.time$、$B = N.time$、$\Delta = A + \mathrm{round}((B-A)\times\text{ratio}) - B$）：

$$f(t)=\begin{cases}
t & t < A\\
A + \mathrm{round}((t-A)\times\text{ratio}) & A \le t < B\ \text{（或 } P \text{ 是最后一点）}\\
t + \Delta & t \ge B
\end{cases}$$

| 区段 | 处理 | 理由 |
| --- | --- | --- |
| 段前（$t<A$） | 不动 | 不受这个时间点影响 |
| 段内（$A \le t < B$） | 按比例缩放，锚 = $A$ | tick rate 在段内恒定，刻数 ×ratio 后现实时长恰好不变 |
| 段后（$t \ge B$） | 整体**平移** $\Delta$ | ★ tick rate 逐段独立设置；段 A 被拉长后只需把边界 $B$ 挪到新位置，段 B 及其后刻坐标平移同样多，它们的现实时间（相对 $B$）完全不变。**若对段后再乘 ratio 就是二次错位** |

**缩放哪些字段**

| 开关 | 字段 | 缺省值 |
| --- | --- | --- |
| `10701`【音乐对齐】 | 所有音符的判定时间、**其后所有**时间点的时间、所有事件的时间、谱面结束时间 | —
| `10702`【长条时长】 | 段内长条的持续时长、判定密度（混凝土） | 混凝土 8 / 玻璃 3 / 密度 8 |
| `10703`【飞行时长】 | 段内音符的基础寿命 | 24 |
| `10704`【事件时间】 | 所有事件的时间 | — |

> `10701` 与 `10704` 都涉及事件时间：`10704` 关掉时事件不动（可单独保留旧位置）。
> 钳制：混凝土 `duration ≥ 1`、玻璃 `duration ≥ 0`（0 = 不延伸）、`density ≥ 1`、`note_base_life ≥ 1`、`end_time ≥ 0`。

> **你会遇到的两个行为**：
> 1. 缩放**不需要重排音符**（换算后顺序天然还是升序）。
> 2. **播放头不跟着缩放** —— 缩放后点撤销，谱面回到原坐标系而播放头停在缩放后的位置。因为播放头是编辑器会话状态、不进撤销快照；它只用于「重开编辑器时回到上次位置」，与音频对齐无关。
> 3. **判定缩放倍数**的现实时长会变窄 ratio 倍（它的窗口是「±k 刻」），这是刻意不做补偿的。
>
> 遍历实现、分刻策略与踩坑记录见 [编辑器实现 - 改 tpb 的同步缩放](编辑器实现.md#改-tpb-的同步缩放实现)。

### 面板通用机制

- **面板隔离**：一次只执行**当前面板**自己的按钮；点了别的面板的按钮会提示 `[编辑器] 该按钮不属于当前面板`（黄色），不会误操作。
- **操作反馈**：操作完成并返回上一级时，新面板顶部会先显示 `[编辑器] {反馈}`（黄色），不会被清屏顶掉。纯提示性文本（灰色斜体）单独一条，不带点击事件。
  - 反馈行末尾**同时**附【撤销】【重做】两个按钮（任意面板可用，点后回到操作所在面板）。**哪些能点**：可撤销 = 有更早的快照、可重做 = 有更新的快照；**不能点的那个变灰且完全没反应**
  - 不产生撤销/重做的操作（保存、改名、设置暂存等）只给**纯文本反馈**，不附按钮
- **播放进度 bossbar**：仅播放时显示，最大值取当前谱面结束时间，播放头逐刻推进，播到末尾自动暂停
- **调试输出**：默认关闭；只在你设了调试开关后才显示播放头位置等信息
- **按钮配色约定**：按钮一律用方括号括起来；**能按的是绿色，不能按的是红色**
- **保存是逐级的**：每打开一级菜单就把要改的属性复制一份，点了该面板的【保存】才逐级上交，直到最顶层才真正写入谱面

### 谱面总表（菜单系统页面 19，已实现 2026-09-19）

把**所有已保存的谱面**列成一张表，每行一张，供玩家**选谱开局**或**选谱进编辑器**。

```panel
====  节奏地图谱面总表 Rhythm axe Maps  ====
{缩进}[▶/⏸] {标题} - {曲师} by {谱师} {mapid}

【🎮 游玩】【✏ 编辑】【🏆 排行榜】【＋新建谱面】【⚙️设置】
【上一页】1/10 共x张谱面【下一页】
```

**怎么用**

- **行首 `[▶/⏸]` 是唯一的行按钮**：点一下 = 选中这张谱面**并开始预览**（再点正在预览的那一行 = 只停预览）。选中的行会缩进并变金色，操作行上的【游玩】【编辑】【排行榜】就是对它生效。
- **没选中谱面时**，【游玩】【编辑】【排行榜】是红色的、点了没反应。
- **每页 10 张**，用页脚的【上一页】【下一页】翻页；只有一页时两个翻页按钮都是红的。
- **没有【关闭】按钮**（聊天栏面板本来就没有窗口可关），进游戏 / 进编辑器时会自动收起。
- **编辑中也能打开总表**（翻看、查谱面 id 都行）；但编辑状态下点【游玩】会被拦下并提示「请先退出编辑器，再来游玩」。

> **选中和预览是全服共享的**：一个人点了 `[▶]`，别人下次刷新看到的是同一张。但预览音只发给**正在看总表的人**，进游戏 / 编辑器前自动停。
> 排序固定为新谱面入队的先后顺序，不提供排序功能。

#### 谱面排行榜（操作行【🏆 排行榜】`11903`，2026-09-30）

操作行点【🏆 排行榜】→ **就地**在聊天栏列出**选中谱面**的玩家前 10 名（不新开页面）。

```
==== 谱面排行榜 ====
谱面：{标题} - {曲师} - {谱面作者}（{mapid}）
  #1 玩家名   12345
  #2 …
【返回总表】　 【编辑成绩】/【完成编辑】
```

- **分数从哪来**：见《谱面存储格式》的「最高分 / 排行榜」一节。
- **【编辑成绩】** 切换编辑模式，开启后每个名次行前面会出现一个 `[x]`，点它删掉那个人的这条成绩。
- **【返回总表】** 回到总表并**保留你原来所在的页**。

> 取榜的扫描算法、复杂度与玩家名解析方式见 [编辑器实现 - 谱面总表](编辑器实现.md#谱面总表菜单系统页面-19)。

### 时间点

- 当点击编辑器主菜单的【时间点】按钮，弹出时间点列表

```panel
 ====时间点列表====
 █时间:120 bpm:150 每小节拍数:4 每拍刻数:8 偏移量:0 判定缩放：1 [编辑][复制][粘贴][删除]
 █时间:320 bpm:180 每小节拍数:6 每拍刻数:12 偏移量:0 判定缩放：1 [编辑][复制][粘贴][删除]
 【新增一个时间点】
```

> █的颜色会随着时间点的颜色变化
> 【复制】：点击后聊天栏提示“已复制时间点信息”，不刷新面板

**红线/绿线 自动计算**：在以下两种情况会把时间点判为红色：
    - BPM直接发生变化
    - 有tick rate 指令执行：当前时间点与前一个时间点相比，其最终 tps 发生变化
    其余情况下该时间点为绿线。
> 红线：bpm或者tps发生变化的时间点，并且认定为新的小节
> 绿线：bpm和tps不变，但是 每小节刻数/每拍刻数/偏移量 发生变化
> 最终 tps = bpm × tpb ÷ 60；判定是否变化时用 ×1000 整数比较 `bpm×tpb×1000`，避免浮点误差

- 使用时间点工具或者点击时间点列表的编辑按钮，在聊天栏弹出统一的控制面板：

```panel
 ====时间点设置====

 [-][+]【使用当前时间】  // 每次 ±1 刻
 BPM：[编辑数值]  // 对话框输入小数（如 175.000），原封不动存储为 Float
 拍号：[-] 4 [+]
 每拍刻数：[-] 8 [+]
 偏移量：[-] 0 [+]
 判定缩放倍数：[-] 1 [+]  // >=1，作用于该时间点起效范围内音符的判定区间（见[音符→属性→判定区间缩放倍数](音符.md#判定区间缩放倍数)）
 颜色：R（红线）← 自动计算
 【上一个时间点】【下一个时间点】← 如果存在则绿色，不存在则红色
 【取消】【确认新增】【复制】【粘贴】         ← 互动的是空白区域或者点击时间点列表的【新增一个时间点】
 【取消】【确认】【复制】【粘贴】【删除】       ← 互动的是已有时间点
```

> 若互动位置为**空白区域**（当前无时间点）：面板底部显示"确认新增"，确认后在当前 time 新增一个时间点，按 time 升序插入数组
> 若互动位置为**已有时间点**：面板底部显示"确认"和"删除"。点击"确认"更新该时间点的值；点击"删除"进入二次确认（首个 time=0 不可删除，提示"不能删除曲目起始时间点"）
> 【粘贴】：如果剪贴板有复制好的时间点信息则绿色，点击后将剪贴板上的信息粘贴给正在编辑的时间点，聊天栏提示“已粘贴时间点信息”并且刷新面板
> **一刻只能一个**：若当前 time 已存在时间点，则提示"[编辑器] 该刻已存在时间点，一刻内只能有一个时间点或事件点"并拒绝新增（时间点与事件点可共存，不受此限制）

> 聊天栏弹出事件点设置，对事件点进行修改：

```panel
====事件点设置====
时间：[-] 128 [+] 【使用当前时间】
指令#1：【编辑指令】 【删除】  // 对话框输入；已有内容时显示命令字符串
指令#2：【编辑指令】 【删除】
...（每条指令一行）
【添加一个指令】  // 在列表末尾追加一条空指令，面板新增对应行

【上一个事件】【下一个事件】
```

- 取消：不添加/修改事件点
- 确认：按时间插入到数组中并保持升序；**若当前时刻已存在事件点**，则提示"[编辑器] 该刻已存在事件点，一刻内只能有一个时间点或事件点"并拒绝新增（时间点与事件点可共存，不受此限制）
- 删除：删除事件点，将事件从数组中删除
- "上一个事件"：播放头跳转到当前时间之前最近的事件
- "下一个事件"：播放头跳转到当前时间之后最近的事件
- 指令通过对话框输入（【编辑指令】）：
- **开头不能带 `/` 号**（直接写指令本体）；**含引号用 `\"` 转义**；超长/复杂指令建议创建 function 文件并在面板中引用（见[字符串输入](#字符串数字输入)）
- 事件可包含多条指令：到时间后按列表顺序逐条执行；未输入内容的空指令自动跳过
- **【复制】/【粘贴】只针对指令列表，不含时间**（2026-10-12）：复制把一个事件点的指令列表存入剪贴板，粘贴只覆盖目标事件点的指令、**保留目标原 time**；列表行按钮与设置面板内的【复制】【粘贴】行为一致（提示文案为“已复制事件信息（仅指令）”/“已粘贴事件指令（保留原时间）”）

  - 【粘贴】：把剪贴板音符信息**覆盖到该音符**，保留该音符原有的 **id** 与 **判定时间**（其余字段全部用剪贴板），一次可撤销，提示“已粘贴音符信息”；剪贴板为空时提示“剪贴板为空，先复制一个音符”；**按钮颜色**：剪贴板有内容时黄色可点、为空时红色

- 点击【批量编辑】时会弹出一个“批量编辑音符”的面板，其内容与音符属性控制面板相同，不过其中显示的数值均为“缺省”，第一次点击面板中的按钮对数值进行修改时会给数值赋默认值。只有在批量编辑中修改的属性才会被写回音符，所有音符写入相同值，未修改的属性保持原值不变；

- 点击【使用玩家注视位置】同理
-【取消】会退出对音符的编辑状态并且将音符的属性重置为进入编辑时的状态
- 【删除音符】点击后会在聊天栏弹出【再次点击我删除此音符】，再次点击删除音符
- **各项删除音符的操作需要注意兼容，防止错删漏删**
- **各项属性操作做好值域钳制，具体的值域范围见音符/属性**
  - 【相对】：在原有属性基础上加减（如原本大小为 1.0，批量编辑中大小 +0.5，则写回后大小为 1.5）
  - 【绝对】：直接覆盖原有属性（如原本大小为 1.0，批量编辑中大小改为 0.5，则写回后大小为 0.5）
  - 点击绝对按钮时，属性值变为0并且按钮切换成相对，点击相对按钮时，属性值变为点击绝对值时的值并且按钮切换成绝对

> 此面板打开时缺失字段即补全，显示值 = 最终写入值。

### 音符（二级菜单）

- 进入方式：音符属性面板点击“击打事件：【进入编辑二级菜单】”
- 编辑对象：hit_events 的**临时副本**（进入时从当前音符复制一份），不直接修改音符

```
====音符击打事件====
{时间} {音符类型} #{音符id}（共 n 条指令）

"say 这是一个音符击打事件" [编辑][复制][粘贴][删除]

【添加指令】 // 在列表末尾追加一条空指令，并立即在面板中新增该指令的一行内容
【取消】【确认】
```

- 空列表（无指令）时：只显示“所属音符”行、【添加指令】、【取消】【确认】
- 【编辑】：点击之后打开一个对话框，对话框里有一个 text 和十个 boolean 用于输入指令和确认判定的启用状态（指令**开头不能带 `/` 号**）
- 【复制】：复制指令内容和启用状态
- 【粘贴】：把复制的内容**覆盖到点击的该行**（剪贴板有内容才可点；非新建，与编辑语义一致）
- 【删除】：移除一条指令
- 【添加指令】：新增一条指令，
- 【确认】：将临时副本写回音符的 hit_events，返回音符属性控制面板
- 【取消】：丢弃临时副本，hit_events 保持进入二级菜单前的原样，返回音符属性控制面板
- 音符属性控制面板的【取消编辑】仍会恢复包括 hit_events 在内的全部属性为进入面板时的状态

```
====全局音符击打音效====

【0】【1】【2】【3】【4】【5】【6】

【返回】

====全局音符击打视效====

【0】【1】【2】【3】【4】【5】【6】

【返回】

====全局音符击打音效#1 / perfect====

type0（音符盒）："playsound minecraft:block.wood.break ..."
type1（木板）："playsound minecraft:block.wood.break ..."
type2（唱片机）："playsound minecraft:block.wood.break ..."
type3（混凝土）："playsound minecraft:block.stone.break ..."
type4（染色玻璃）：""

【确定】【取消】
```

- 【0】-【6】：选择要**查看**的击打音效/视效组编号
  - 组1整合旧组0-4；组6保留旧通用组；组2-5留空
- 详情面板**只读**显示当前组下五种音符 type 的各判定情况
  - 音效查 `sounds[组][type][情况]`，视效查 `particles[组][type][情况]`
- 全局反馈（音效/粒子）**不在编辑器面板里填**，要改请直接改数据包里对应的配置。
- **音效和粒子都填不带 `/` 的完整命令**（如 `playsound minecraft:block.note_block.pling master @a ~ ~ ~ 1 1`；空值 = 无反馈）
- 格子里的内容会**当成指令执行**，所以除了音效/粒子命令，也可以填其它命令（比如调用一个 function）。

### 工具选项栏（把工具放副手打开）

把**任意编辑器工具放进副手**，就会在聊天栏弹出「{工具名}选项栏」，里面是这个工具自己的设置项。

| 工具 | 可调内容 |
| --- | --- |
| 音符类工具 | **坐标锁定**（X / Y / Z 三轴各自开关 + 锁定的具体数值）、**网格尺寸** |
| 选择工具 | **网格尺寸**（与音符工具的**互相独立**） |
| 其他工具（方向控件、播放控件等） | 显示「该工具没有设置项」 |

- **坐标锁定**：锁定某轴后，画面上会出现一条**该轴颜色的平面粒子**（X 红 / Y 绿 / Z 淡蓝）标示锁定位置；右键放置新音符时，该轴会被强制写为锁定值。**只影响右键放置新音符**，复制/粘贴、分布·填充、在面板里改判定位置都不受影响。锁定是全局设置，不随谱面切换，也不受【恢复默认】影响。
- **网格尺寸**：决定右键放置的音符对齐世界网格的疏密，四档 **0.1 / 0.25 / 0.5 / 1**（默认 1）。格点始终包含方块中心；档位越大越粗，1 档就等于旧的「一律放方块中心」。只作用于右键放置与光标玻璃的吸附，镜像/旋转/翻转/分布填充/粘贴都不吸附（否则对称性会被破坏）；被锁定的轴不参与吸附。
- **选择工具的网格尺寸**同理，决定**框选两角**对齐网格的疏密（选区因此能精确到亚方块）。
- 关闭选项栏：再按一次副手工具、或切走副手物品即可；也可以按选项栏里的返回。

> 「锁定后 Y 轴仍然 +0.1」是混凝土类型音符的固有行为（它本来就放在方块中心上方 0.1 格），不是锁定失效。
> 网格吸附的具体公式、相位偏移与实现位置见 [编辑器实现 - 音符工具的网格尺寸与吸附实现](编辑器实现.md#音符工具的网格尺寸与吸附实现)。

### 音符类工具

- 手持音符类工具时，会出现黄色发光玻璃作为**注视位置**

- **音符工具**

手持音符工具时，可以进行如下操作：

- 右键后在发光的位置放置音符：判定位置对齐该方块中心（整数坐标 +0.5），判定时间 time = 当前播放头时间。

- 放置出音符的属性会继承**同类音符中往前最近的一个**（在**同类型里**找：判定时间不晚于当前音符、时间最靠后的那一个；同刻则取最后放置的）。除了 **判定时间、id、击打事件、判定位置（由放置位置覆盖）** 以外全部继承；找不到同类（如第一个音符）则起始位置用默认值，其余用默认值

- 使用混凝土工具放置音符时，会放在方块中心再往上0.1格的位置而不像其他音符一样放在方块中心

- **蹲下切换配对音符**：**蹲下**时，所有音符盒/木板工具（快捷栏/选择工具槽/副手，凡持有者）一起切为**配对类型**（音符盒↔木板），造型与名字随之切换并带**灰字提示**（站立：`蹲下切换为木板`/`蹲下切换为音符盒`；蹲下：`站立切换回音符盒`/`站立切换回木板`），此时右键放置的就是**配对类型**的音符；染色玻璃↔混凝土同理

  - 蹲下只是**换外观和名字**，物品的**身份不随之改变**；真正放置成什么类型，按「原本是哪件工具」+「当前是否蹲下」决定
  - 这套切换由常驻检测统一维护（遍历全背包后逐槽更新）

- **事件点/时间点工具**（同一件工具，随蹲下变形）

  - **站立**：事件点工具（命令方块矿车造型），右键作用于**当前播放头** (`time = #playhead`)——该刻无事件点则**创建**并打开设置面板（`commands=[]`，不继承任何东西）；该刻已有事件点则**直接打开**该事件点的设置面板（不创建）
  - **蹲下**：时间点工具（时钟造型），右键作用于**当前播放头**——该刻无时间点则**创建**（其余字段 `bpm`/拍号/每拍刻数/偏移/判定缩放 **完全继承上一个时间点**：按时间升序、不晚于播放头且最靠后的那个；无上一个则默认 150 BPM/4 拍/8 刻/偏移 0/判定缩放 1）并打开设置面板；该刻已有时间点则**直接打开**该时间点的设置面板（不创建）
  - 站/蹲下状态切换时，工具的**名称与造型自动切换**（站立显示【事件点工具】+ 命令方块矿车，蹲下显示【时间点工具】+ 时钟）
  - 站/蹲下状态切换是**自动的**，不需要手动换工具。

- **选择工具**

- 以两个对角方块的方式来选定立方体范围内的音符：第一次右键确认第一个角，第二次右键确认第二个角并确认选区（弹出「已选定音符列表」面板，随后自动回到选角1状态）
- 实体显示选区范围发绿色光（缩放过后的黄绿色染色玻璃，确认后消失）
- 被选定的音符发黄色光（展示实体）
- **蹲下时工具变形**：金斧头换成**钻斧头**、名字从绿色【选择工具】变成淡蓝色【时间段选择】，并像其他蹲下变体的工具一样带**灰字提示**（站立：`蹲下为时间段选择`；蹲下：`站立为框选音符`）；**蹲下时不显示黄绿玻璃预览**（时间段选择不需要方块光标，只用 mod 时间轴上的入点/出点与范围色带）
- 确认选区后自动弹出「已选定音符列表」面板（面板 18），显示选中音符并支持编辑/复制/粘贴/删除；【返回】清空 selection 与高亮

#### 时间段选择（蹲下 + 右键）

使用选择工具，还可以选择某一时间段（或某一刻）内的音符：

- **蹲下 + 右键**（金斧头）：第一次把**当前播放头**设为**入点**，第二次把当前播放头设为**出点**，并按下面的判定选中音符（出点小于入点时自动取 min/max，所以反向拉也行），随后弹出「已选定音符列表」；区间内没有音符则提示并回主菜单
  - 判定依据：**判定时间落在 `[入点, 出点]` 内（含两端）**；或**长音符**（**仅混凝土**，持续时长 ≥ 1）的自有跨度 `[判定时间, 判定时间+持续时长−1]` 与区间**有交集** —— 这样「判定时间在区间外、但持续时间延伸进区间」的混凝土也能被选中（玻璃不适用此条）
- 入点/出点会**保留显示**在 mod 可视化时间轴上：**七行贯通的半透明色带**（从入点那一列的左缘一直盖到出点那一列的**右缘**，最后一列整列覆盖）+ 两端各一个**拉满七行的大中括号**（竖杆 + 顶/底横臂、中间留缝）。括号方向由区间 `min/max` 决定 —— 所以**第二次点的刻比第一次早时会自动翻过来**，两条括号始终把范围夹在中间；只设了入点时先画左括号（等待出点的反馈）。色带与中括号**画在最上层**（盖住刻度线/音符/数量角标，仅播放头在其上）；括号样式：**上下两半各占 2 行高**（竖杆 2px + 顶/底横臂 5px），中间留大空隙（约 3 行）；位置在色带**内侧** —— 左括号贴左端刻度线**右边**，右括号再往右 1px、**压到右端刻度线上**
- 设完出点后**再次蹲右键 = 开启新一轮**：当前播放头变新入点，旧的出点与上一轮选中一并清掉
- 站立右键仍是原来的立方体两点框选，两者状态互不干扰；退出编辑器、切谱面、重给工具都会清掉入点/出点

> **选择工具的协作占用**：同一时间只允许一个人驱动选择工具（它是「两次右键定两角」的状态机）。非占用者右键会提示「选择工具已被占用」；**放下工具即释放**，下一位手持者立刻接任，并能接着用前一位设好的第一角继续框选。
>
> 右击检测方式、状态机与判定遍历实现、黄光同步、mod 侧色带/括号绘制参数见 [编辑器实现 - 选择工具与时间段选择](编辑器实现.md#选择工具与时间段选择实现)。

- **播放/暂停工具**（绿宝石造型·绿名；**站立名【播放/暂停】、蹲下名【添加/删除记录点】**）：
  - **站立**：普通播放/暂停；播放中→暂停时，若存在记录点则跳回记录点，**暂停不消除记录点**
  - **蹲下**=记录点开关，**只操作记录点、不控制播放/暂停**：播放头**正停在记录点上**（且已有记录点）→ **删除**它（不暂停、不跳转）；否则 → 把**当前播放头**记为记录点（覆盖旧值）并发一行提示
  - 记录点属性：**持久**（一直有效，可反复跳回；只在「在记录点处蹲下右键」时删除）；不随暂停/播放/重开谱面自动清除
  - 名字与提示：**站立** = 名【播放/暂停】+ 提示「蹲下播放以添加记录点」；**蹲下** = 名【添加/删除记录点】+ 提示「下次暂停会回到记录点，在记录点处蹲下右键删除记录点」
  - 聊天栏提示（前缀金色 / 正文绿色 / 刻数金色；**只有添加那条折两行**，逗号留在第一行末尾、不在行首）：

    | 时机 | 内容 |
    | --- | --- |
    | 添加 / 覆盖 | `[编辑器] 已添加记录点<刻数>，` 换行 `在记录点处蹲下右键可以清除记录点，移动播放头蹲下右键可以移动当前记录点` |
    | 删除 | `[编辑器] 已删除记录点<刻数>，蹲下右键可以创建新的记录点`（单行） |

- **蹲下瞬间**，背包里（快捷栏 0-8、主背包第 1 格、副手）**所有编辑工具**一起切换成蹲下形态，松开立刻换回 —— 不需要先把它拿在手上。
- **主背包第 2 格之后的工具不会跟随切换**（只扫描可能放工具的那几个槽）。
- 工具名/造型的切换逻辑与性能处理见 [编辑器实现 - 工具常驻机制](编辑器实现.md#工具常驻机制)。

## 通用机制

贯穿整个编辑过程、不属于某个特定步骤的机制。

### 字符串/数字输入

谱面 id、标题、曲师、谱面作者、音乐文件、预览音频、BPM、事件指令等需要手动输入时，统一用**对话框**。

**使用者会遇到的能力边界**（实测）：

- 普通单行文本 ✅；多行文本 ✅（提交时换行被压成一行）
- **引号 `"` 必须自己写成转义形式 `\"`**，否则提交会失败
- **超长文本会失败**（对话框走聊天命令，有长度上限；输入太长会断连）。含引号/超长的复杂指令建议**改成 function 文件**再引用
- **数字框输错会红字提示「输入无效」**，原来的值保持不变（不会写进一个错误值，也不会静默没反应）
- 标题要输入 **JSON 文本组件**（如 `{"text":"标题","color":"red"}` 或带引号的 `"新手教程"`），**不能是裸纯文本、组件里不能含空格**
- BPM 直接输入小数（如 `175.000`），原样存储

> ⚠️ **对话框的改动要重进存档才生效**：改完需要**退出世界再进入**（不必重启游戏），只跑 reload 不够。

输入校验的标准写法（四步法）、外层安全转发机制、已拆层的对话框清单见 [编辑器实现 - 字符串与数字输入](编辑器实现.md#字符串与数字输入实现)。

**对话框与聊天栏面板的职责划分**：

- 聊天栏 tellraw 面板负责**动态展示与操作**：显示当前值、`[-][+]` 加减、需要随游戏状态实时刷新的内容（改 mcfunction + reload 即可）
- 对话框负责**静态输入**：文本/数字/单选/开关等原生输入控件；面板上的【编辑文本】是打开对应对话框的入口
- 分配优先级：先看使用场景哪个更直观、更容易；其次考虑性能消耗与实现难度

> 命令链上限、重活与渲染分开、大操作提示、复制/剪切/删除的语义，见 [编辑器实现 - 命令链与分刻政策](编辑器实现.md#命令链与分刻政策)。
## 多人协作（编辑器）

**多人可以同时编辑同一张谱面**：所有协作成员共享同一份工作副本 —— 同一套面板、同一个播放头、同一份选区 / 剪贴板 / 撤销栈。也就是说，**大家是在一起编同一张谱**，不是各编各的。

### 邀请与踢出

| 操作 | 怎么做 |
| --- | --- |
| 拿到协作工具 | 主菜单点【领取协作工具】，它会放进你的**背包第 1 格**（不点就不发） |
| 邀请 | 手持它（【协作·邀请】，命名牌外观）**右键**队友 |
| 踢出 | 手持它**蹲下右键**队友（物品会同时变成【协作·踢出】的屏障外观） |
| 收工 | 由**会话主**（打开这张谱面的那个人）正常退出编辑器，所有人一起退出 |

- **会话主不可被踢**。
- 邀请 / 踢出都会**广播**给所有在场编辑者；被踢的人会收到说明，音乐会被停。
- **工具不会收回**：被踢或退出后，编辑工具仍留在背包里，但**已经失效**——右键不会有任何反应。重新进入编辑器时工具会被覆盖刷新。
- **加入时你的快捷栏 / 背包工具会被覆盖**（会发一套编辑工具给你，**不备份你原来的物品**）。

### 已知限制（刻意为之，不是 bug）

- **面板是共享的**：两个人不能各看各的面板、各调各的音符 —— 打开的是同一份。
- **锚点全局唯一**：两人同时用镜像 / 旋转会互相影响（锚点是整张谱共用的一个点）。
- **判定放宽**：真实判定模式下，**任一**编辑者看 / 点 / 站进判定区就算命中。
- **人越多越慢**：每次重绘面板都要为每个成员各算一遍，人多时明显卡顿（聊天栏面板没有分页级别的优化）。
- **退出 / 切换 / 删除的确认框不同步**：别人点这些确认框时，你看到的是主菜单（其余面板都能同步）。
- **同时点同一个按钮会有「请稍候」**：连续快速点击时第二个人可能收到这条提示。

> 目标识别、触发链、渲染同步、操作者唯一化与并发锁的实现见 [编辑器实现 - 多人协作实现要点](编辑器实现.md#多人协作实现要点)。
