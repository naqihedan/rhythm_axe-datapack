# 音符（note）

谱面的核心内容。

## 组成

所有音符都由「展示实体」和「交互实体」组成：展示实体负责视觉效果，交互实体用于判定。混凝土和染色玻璃还需要额外的判定检测。此外，部分音符会带一条引导线（见[引导线](#引导线following_point)）。

## 属性

每个音符实例都有的属性。缺失的可编辑字段会按默认值自动补全；`type` 与 `position` 为必填项。

### 音符字段速查

| 字段 | 类型 | 必填 | 默认值 | 适用类型 | 说明 |
| --- | --- | --- | --- | --- | --- |
| `id` | Int | 是 | — | 全部 | 音符唯一 id，新建时分配，稳定不变 |
| `type` | Byte | 是 | — | 全部 | 0=音符盒 1=木板 2=唱片机 3=混凝土 4=染色玻璃 |
| `time` | Int | 是 | — | 全部 | 判定时间（大P的时刻），≥0 |
| `ignore_note_speed` | Bool | 否 | false | 全部 | 出生时刻是否无视流速（见[无视流速](#无视流速ignore_note_speed)） |
| `duration` | Int | 否 | 混凝土 8 / 玻璃 3 | 混凝土、玻璃 | 持续时长（刻）。混凝土 ≥1；玻璃 ≥0 |
| `color` | Byte | 否 | 0/1/2 型 0（未设置）/ 混凝土 9 / 玻璃 6 | 全部 | 1~16 染色。混凝土/玻璃 = 自身外观色；音符盒/木板/唱片机 = 引导线颜色 |
| `density` | Int | 否 | 8 | 混凝土 | 判定密度，≥1 |
| `size` | Float | 否 | 1.0 | 全部 | 大小（格），≥0.1 |
| `position` | [Double;3] | 是 | 音符放置位置 | 全部 | 判定位置（绝对世界坐标），精度 0.1 |
| `start_pos` | [Double;3] | 否 | [0,0,24] | 全部 | 起始位置（相对判定位置），精度 0.1 |
| `note_base_life` | Int | 否 | 24 | 全部 | 基础寿命，≥1 |
| `anim_easing` | Int | 否 | 1 | 全部 | 缓动类型：1=缓入 2=缓出 3=缓入缓出 |
| `anim_power` | Int | 否 | 1 | 全部 | 缓动幂次 1~5（1=线性） |
| `hitsound` | Int | 否 | 0 | 全部 | 0=跟随全局，1~6=覆盖为对应音效组 |
| `hit_particles` | Int | 否 | 0 | 全部 | 0=跟随全局，1~6=覆盖为对应粒子组 |
| `hit_events` | List | 否 | [] | 全部 | 击打事件列表（每个音符单独存储，不继承） |
| `following_point` | Bool | 否 | true | 音符盒/木板/唱片机 | 是否生成引导线（从本音符连向后面第一个 0/1/2 音符） |

### 判定时间|time

> 整型，≥0

音符被判定（大P）的时间，也是它在**时间轴上的位置**。

### 起始时间/出生时间|birth_time

> 整型，游玩时按音符属性自动计算

音符出生的时间，由基础寿命和流速共同决定：

> 起始时间 = 判定时间 − 基础寿命 × 16 ÷ 流速（流速在[设置](设置.md#设置)中调整）。如寿命 32、流速 20 → 32×16/20 = 25.6 刻。

开启「无视流速」时按[无视流速](#无视流速ignore_note_speed)的规则计算。

### 无视流速|ignore_note_speed

> 布尔，默认 false

- true：起始时间 = 判定时间 − 基础寿命
- false：起始时间 = 判定时间 − 基础寿命 × 16 ÷ 流速

### 类型|type

> 整型：0=音符盒 1=木板 2=唱片机 3=混凝土 4=染色玻璃，默认 0

音符的种类。各类型的判定方式详见[判定方式](#判定方式)：

- 音符盒：视线对准即判定。
- 木板：外观是音符盒边框加木板内部，判定方式同音符盒，但判定更宽。
- 唱片机：外观是黄色描边的音符盒，需要左右键交互才能判定。
- 染色玻璃（墙）：拥有碰撞体积，玩家接触时扣血并进入扣血冷却。
- 混凝土（hold，长条）：需要玩家处于判定区域才能判定。

> 混凝土持续时长为 0 时没有判定；常规谱面不得使用。

### 持续时长|duration

> 整型，单位刻。混凝土 ≥1、染色玻璃 ≥0；默认混凝土 8 / 玻璃 3

对混凝土和染色玻璃有效：

- 混凝土：决定长条的长度，不受流速影响。
- 染色玻璃：决定音符越过判定位置后还能继续延伸多久，受流速影响。为 0 时不延伸。

### 颜色|color

> 整型 1~16；默认：音符盒/木板/唱片机 0（未设置）/ 混凝土 9（黄绿）/ 染色玻璃 6（红）
> 1=白 2=灰 3=淡灰 4=黑 5=棕 6=红 7=橙 8=黄 9=黄绿 10=绿 11=青 12=淡蓝 13=蓝 14=紫 15=品红 16=粉

- 混凝土、染色玻璃：自身的外观颜色。
- 音符盒、木板、唱片机：决定其[引导线](#引导线following_point)的颜色；0 或缺失为未设置，引导线呈青色。

### 判定密度|density

> 整型 ≥1

只对混凝土有效，决定 hold 判定点的密度。例如密度 8 时，每 8 刻产生一个判定点。

### 大小|size

> 浮点数，单位格，≥0.1，默认 1.0

音符的大小，即展示实体与交互实体的体积，默认 1³。

- 音符盒/木板/唱片机/玻璃：大小就是它的视觉大小与判定空间大小。
- 混凝土：决定长条的宽高，长度由持续时长决定；判定区域为固定尺寸，不受 size 影响（见[混凝土的判定方式](#混凝土的判定方式)）。

### 判定位置|position

> 三个小数，精确到 0.1

音符判定大P所在的空间位置（世界坐标）。

### 起始位置/出生位置|start_pos

> 三个小数，精确到 0.1

音符出生时的空间位置（相对判定位置）。

### 动画类型|anim_easing, anim_power

> 两个整型：`anim_easing`（缓动类型）与 `anim_power`（缓动幂次），默认均为 1

控制音符移动的缓动曲线（详见[工具组件/展示实体动画系统](工具组件.md#展示实体动画系统display-animation)）。

| 字段 | 取值 |
| --- | --- |
| `anim_easing` | 1=缓入，2=缓出，3=缓入缓出 |
| `anim_power` | 1~5（1=线性） |

- `anim_power=1` 时三种缓动完全等价（都是线性），要看出差别需把幂次调到 ≥2。
- 染色玻璃越过判定位置的那一段会自动镜像缓动（缓入↔缓出，缓入缓出不变），使穿过判定位置时速度连续。

### 基础寿命和实际寿命|note_base_life, note_life

> 整型，≥1

- 基础寿命 `note_base_life`：谱面设定的音符寿命。
- 实际寿命 `note_life` = 基础寿命 × 16 ÷ 流速（下取整），此后每刻递减 1；到判定时刻为 0，之后继续递减为负值。

判定瞬间的寿命决定判定等级。缩放倍数 = 1 时：

- 寿命 0 → perfect（大P）
- 寿命 ±1 → perfect_early / perfect_late
- 寿命 ±2 → good_early / good_late
- 寿命 +3 → bad
- 越过 goodL 仍无击打 → miss

实际寿命与流速共同决定音符的出生时间。

### 引导线|following_point

> 布尔，true 时生成，默认 true；仅音符盒/木板/唱片机有效

灵感来自 osu!。引导线是一条连接前后两个音符中心、起引导作用的线，外观为被拉长的染色玻璃。

- **生成**：当本音符 `following_point` 为 true、且其后存在下一个 0/1/2 音符（中间的混凝土/玻璃跳过）时，以本音符为起点生成一条连向那个音符的引导线；后一个音符是否开启不影响。
- **颜色**：取起点音符的 `color`（未设置时为青色）。
- **移动**：引导线跟随音符移动，每刻计算角度与长度。前一个音符到达判定位置前，一端连住后一个音符的当前位置，另一端朝前一个音符的判定位置收缩（带插值动画）。
- **消失**：前一个音符到达判定位置后，线段逐渐缩短；后一个音符到达判定位置时长度缩为 0，完全消失。

### 音符事件|hitsound, hit_particles, hit_events

> 三个字段，决定音符生成/判定时执行的音效、粒子与指令

音符被生成或判定后触发的事件，主要有三类：

- **击打音效** `hitsound`：生成/判定时的声响。
- **击打视效** `hit_particles`：生成/判定时的粒子。
- **击打事件** `hit_events`：生成/判定时执行的一条或多条指令。每个音符单独存储，放置时不继承上一个音符。

组号语义（`hitsound` / `hit_particles` 通用）：

| 值 | 含义 |
| --- | --- |
| 0（默认） | 跟随全局设置 `note_hitsound` / `note_particle` |
| 1~6 | 覆盖全局，直接使用对应组 |

各反馈按「触发情况」选取，`hit_events` 逐情况决定是否启用：

- `spawn`：音符开始移动那一刻触发（执行一次）
- `tick`：开始移动后每一刻触发（直到判定/清除）
- `bad` / `good_early` / `perfect_early` / `perfect` / `perfect_late` / `good_late` / `miss`：判定时触发
- `damage`：玻璃撞墙扣血时触发

> 音符缺 `hit_events` 时按空列表处理（无指令可执行）；`hitsound` / `hit_particles` 为 0 时跟随全局设置。

#### 击打音效

即 `hitsound`，音符生成或判定时发出的声响（若该组定义了 `spawn`，生成时也播放）。

音效组是一张全局表，按三个维度选取内容：

| 维度 | 取值 | 说明 |
| --- | --- | --- |
| ① 组号 | `0~6` | 音符 `hitsound` 指向的组 |
| ② 音符类型 | 0=音符盒 1=木板 2=唱片机 3=混凝土 4=染色玻璃 | 同组内不同音符类型可给不同反馈 |
| ③ 情况 | `spawn` / `bad` / `good_early` / `perfect_early` / `perfect` / `perfect_late` / `good_late` / `miss` / `damage` | 触发时机 |

每个格子存的是一条完整可执行指令（不是音效 id），判定时直接执行：

| 位置 | 值示例 |
| --- | --- |
| 组 1 · 音符盒 · perfect | `playsound minecraft:block.wood.break master @a ~ ~ ~ 1 1` |

各组预设内容：

| 组 | 内容 |
| --- | --- |
| `0` | 空 |
| `1` | 按音符类型给出对应的方块破坏音效 |
| `2~6` | 空（留给自定义） |

#### 击打视效

即 `hit_particles`，音符生成或判定时产生的粒子效果（若该组定义了 `spawn`，生成时也播放）。

结构与击打音效完全一致，同样按「组号 × 音符类型 × 情况」选取，只是格子里存的是粒子指令：

| 位置 | 值示例 |
| --- | --- |
| 组 1 · 音符盒 · perfect | `particle minecraft:block{block_state:"minecraft:note_block"} ~ ~ ~ 0.3 0.3 0.3 0 50 force @a` |

#### 击打事件

音符判定后执行的指令。常见用法：

- goodE–goodL 启用、其余禁用 —— 新添加事件时的默认值。
- `spawn` 启用 —— 一般与自定义出生时间搭配。
- `tick` 启用 —— 用于音符飞行过程中的轨迹/循环特效。
- `bad` 与 `miss` 启用 —— 用于判定失败的惩罚。
- `damage` 启用 —— 用于玻璃撞墙扣血时的惩罚/提示。

## 行为

### 生成

- 在判定位置生成一个展示实体。
- 在起始位置生成交互实体，套住展示实体用于判定检测。

> **交互实体 Y 偏移（关键）**：交互实体 `Pos` 的 Y 是**脚底**（碰撞箱底部），而展示实体 `Pos` 的 Y 是**方块中心**。若两者直接重叠，交互实体的碰撞箱（从脚底起、高 = 音符大小）会整体偏上，只盖住展示实体上半部分。
>
> 因此交互实体 Y 需 **− 音符大小 × 0.5**：碰撞箱底部落在展示实体中心下方半格、顶部落在中心上方半格，正好**完全包裹展示实体**（即"交互实体嵌套展示实体、两者中心重合"）。玩家注视/点击展示模型时视线/点击必定命中交互实体。**生成时与每刻移动时都要应用该偏移**。

### 移动

音符从起始位置移动到判定位置，在判定时刻（寿命 0）恰好到达，速度 = 距离 ÷ 基础寿命。移动曲线由[动画类型](#动画类型anim_easing-anim_power)控制，默认为匀速直线。各类型的移动形态：

- **音符盒 / 木板 / 唱片机**：沿直线飞到判定位置后停住，等待判定窗口结束。
- **染色玻璃**：到达判定位置后仍按同方向继续前进，穿过的距离由持续时长决定。
- **混凝土**：呈长条，经历「拉伸 → 平移 → 收缩」——头端在判定时刻到达判定区域、尾端在出窗时抵达，中间整条经过判定区域。

### 判定

对音符进行**符合条件的操作**即可判定，判定等级取决于判定瞬间的音符寿命（见[判定区间](#判定区间)、[判定类型/判定等级](#判定类型判定等级)）。各类型的判定操作：

- **音符盒 / 木板**：视线对准即判定。
- **唱片机**：需要左右键点击。
- **混凝土**：需要玩家身处判定区域（踩住长条）。
- **染色玻璃**：是带碰撞的墙，玩家碰到会扣血并进入扣血冷却。

#### 同一刻判定限制

每刻只判定最接近玩家（寿命最小，即判定时间最靠前）的那一批音符，且**只有音符盒参与这一竞争**：

- 木板在寿命 > 0 时即使被注视也不会立即判定（见[木板的判定方式](#木板的判定方式)），可能挡住音符盒的判定。
- 唱片机每刻只能与一个交互实体交互，天然每刻只能判定一个。
- 混凝土（站位判定）、染色玻璃（碰撞扣血）与视线无关，不参与竞争。

补充规则：

- 该限制只适用于寿命 > 0 的音符。寿命 ≤ 0 的音符叠在判定位置，各自独立判定，同刻可以一起判多个。
- 被压制的音符本刻不判、也不惩罚，下一刻寿命 −1 后重新参与；若因此越过判定窗口，则照常 miss。
- 判定时间相同（寿命相同）的多个音符可以被同时判定。
- 多个玩家各自独立判定：不同玩家在同一判定时刻可以各判一批。
- 处于判定保护状态的音符不占用判定名额。

这一规则让音符盒与木板在谱面中的定位更清晰：

- 音符盒更「重」，前后两个音符盒在时间和空间上都更稀疏，一般半拍/一格，方便玩家晃动视角进行判定。
- 木板更「轻」，可与判定保护配合，做出更密集的小位移，例如四分之一拍/一格及以下。

#### 判定方式

##### 音符盒的判定方式

- 视线与音符盒相交即判定，判定等级取决于相交瞬间的音符寿命。
- **过早瞄准保护**：若在 bad 前一刻（判定时间 −3×缩放倍数）准星就已停在「完美判定区域」（以判定位置为中心、约音符大小的一片区域）内，则暂不判定，只记录此时的寿命；到寿命 0 时，按保护期间最后一次记录的寿命结算判定等级。
  - bad 前一刻准星没压在完美判定区域：按视线与音符相交那一刻的寿命判定。
  - bad 前一刻准星压在完美判定区域：
    - 一直压到大P → 大P。
    - 在 [bad, perfect_early] 区间内相交过、但准星提前移开，且到大P时没回来 → 按记录下的寿命判定（只是晚一点的 bad/goodE/perfectE）。
    - 在该区间内没相交过 → 同上第一种。

> 判定视线的有效长度约 4.5 格：音符距玩家眼睛超过该距离即视为不可判定（即使视线相交）。

##### 木板的判定方式

- 简化版音符盒：视线与木板相交可判定，但判定时机推迟到抵达判定位置之后，且判定更宽。
- 木板的判定保护就是「先记录、后结算」：
  - 寿命 ≥ 1 时被视线穿透 → 只记录寿命，不当场判。
  - 寿命 ≤ 0 时 → 只要记录过就一定判大P（此刻是否仍被注视都算）；从未记录但此刻看着，同样判大P。
  - 从头到尾既没记录、也没看着 → 出窗静默清除。
- 没有 bad 判定，也没有 miss 判定；goodE/L、perfectE/L 区间内取得的判定都会转换为大P。

##### 唱片机的判定方式

- 进阶版音符盒：判定方式是对唱片机进行左右键交互，包含 bad、good、perfect、miss 全部判定种类。
- 点击时按当前寿命取得判定等级；过早/过晚（寿命不在判定窗口内）的点击则忽略。
- **判定保护（末刻兜底）**：到判定区间最后一刻（goodL）仍未点击时——
  - 判定区间内视线与唱片机相交过 → good_late；
  - 视线始终与唱片机相离 → miss。

##### 染色玻璃的判定方式

- 墙壁障碍：玻璃中心周围一小块区域与玩家判定箱相交即扣血。
- 只扣玩法血量，不影响玩家真实血量。
- 扣血后进入扣血冷却（时长由全局设置决定），冷却时间内不会被撞掉血。

##### 混凝土的判定方式

- 需要踩住的长条：判定区间内玩家须处于判定区域内才能判定。判定区域尺寸固定，不受音符 size 影响。
- 长条按判定密度分成若干段落，每段只要玩家在判定区域内即判大P；若某段最后一刻玩家仍不在区域内，则该段 miss。
- **首段过早离开保护**：若玩家在判定区间内进过区域，则记录寿命；若在长条头抵达判定位置之前就离开、且直到第一段结束都没回来，则第一段按玩家在区域内最后一刻记录的寿命结算。
- **长条过短保护**：若最后一段的持续时长 < 3×缩放倍数，则在「判定时刻 + 持续时长」起的这段窗口内，玩家进入判定区域仍能完成最后一段的判定，等级取决于结算时「寿命 + 持续时长」对应的判定区间（最差 goodL，再晚即 miss）。

判定区域的形状：

- 若起始位置到判定位置在水平面上距离 > 1：为「沿前进方向 4 格长 × 1 格宽、竖直上下各 4 格（共 8 格高）」的有向包围盒。
- 否则：以判定点为中心的水平 3×3，竖直从判定点向上 4 格。

#### 判定反馈

判定后给出的反馈，分为基本反馈与可自定义反馈：

- **基本反馈**：物品栏上方的 title、聊天栏文字。
- **自定义反馈**：
  - 声音反馈 `hitsound`、视觉反馈 `hit_particles`、事件反馈 `hit_events`（执行自定义指令）。
  - 反馈按「组号 × 音符类型 × 情况」选取；`hitsound`/`hit_particles` 为 0 时先取全局设置里的组号，1~6 则直接用对应组（见[音符事件](#音符事件hitsound-hit_particles-hit_events)）。

### 自然消亡/出窗

未判定音符的出窗路径：

| 类型 | 出窗时机 | 行为 |
| --- | --- | --- |
| 音符盒 / 唱片机 | 越过 goodL 末刻 | miss（有判定反馈） |
| 木板 | 越过 goodL 末刻 | 静默清除（无 miss） |
| 混凝土 | 长条走完一段延迟后 | 静默清除 |
| 染色玻璃 | 穿过段走完一段延迟后 | 静默清除 |

> 木板若在出窗前被视线穿透记录过，会在寿命 ≤ 0 时判大P，走不到静默清除这一步。

## 名词解释

### 判定保护

不是音符属性、不可在音符控制面板设置，由判定系统在游戏运行时维护。作用于音符盒、木板、混凝土、唱片机，每种音符各有属于自己的保护机制：

- 音符盒：提前瞄准保护。
- 木板：判定天然「先记录、后结算」，判定时机已推迟到抵达判定位置。
- 混凝土：首段长条过早离开保护、长条过短保护。
- 唱片机：判定区间最后一刻的视线兜底（good_late / miss）。

### 判定区间缩放倍数

不是音符属性、不可在音符控制面板设置，通过时间点设置更改。整型 ≥1，默认 1，决定了 perfectE/L、goodE/L、bad 的判定区间长度。

主要为了解决谱面 tps 过高时判定区间时长发生急剧缩小、导致难度失衡的问题；可在时间点设置中更改其作用范围内音符的判定缩放倍数。

- 缩放倍数 = 1 时：bad = +3，goodE/L = ±2，perfectE/L = ±1，miss = −2。
- 缩放倍数 = 2 时：bad = +6~+5，goodE/L = +4~+3 与 −3~−4，perfectE/L = +2~+1 与 −1~−2，miss = −4。

无论缩放倍数如何，PERFECT 总在寿命 0，miss 总在最后一刻。（±数字指音符被判定时的寿命值）

### 判定区间

指一个音符能被判定且不重置 combo 的时间区间，单位是游戏刻，一般用 ±数字（相对判定时刻的寿命值）表示。每个判定等级都有自己的判定区间。

默认情况下，七种不同判定的时长都是 1 刻；通过更改时间点的判定区间缩放倍数，可以改变除大P外所有判定类型的时长。

### 判定类型/判定等级

| 种类 | 别名 | 判定区间（默认） | combo | 计分权重 | FC/AP 标签 | 血量 | 颜色 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| bad | missE | +3 | 重置 | 3rd（+0） | 0 | 不影响 | dark_aqua |
| good_early | goodE | +2 | +1 | 2nd（+1） | 1 | 不影响 | green |
| perfect_early | perfectE | +1 | +1 | 1st（+2） | 2 | 不影响 | yellow |
| perfect | PERFECT（大P） | 0 | +1 | 1st（+2），总分 +1 | 2 | 不影响 | gold |
| perfect_late | perfectL | −1 | +1 | 1st（+2） | 2 | 不影响 | yellow |
| good_late | goodL | −2 | +1 | 2nd（+1） | 1 | 不影响 | green |
| miss | missL | −2（goodL 末刻） | 重置 | 3rd（+0） | 0 | 不影响 | gray |
| miss（玻璃） | 撞墙 | 玩家与玻璃接触时 | 不变 | 不变 | 不变 | −1 | red |

FC/AP 标签：取得判定时，在现有 FC/AP 标签与该判定的 FC/AP 标签中取最小值作为新标签，0=无，1=FC，2=AP。

> 判定区间列数值为缩放倍数 = 1 时的默认值；实际窗口长度 = 表中数值 × 判定区间缩放倍数（见[判定区间缩放倍数](#判定区间缩放倍数)）。
