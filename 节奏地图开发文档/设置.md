> 🤖 **调试等级**
>
> - 介绍
>
> 目前调试等级分两档。一档会输出不刷屏，单次执行的调试信息；第二档输出的调试信息很可能会导致刷屏。
>
> - 规范：
>   1. 所有调试信息前带`[调试.lv*]`前缀，然后可以根据要输出的信息再加前缀，如`[编辑器]`，也可以不加
>   2. 根据debug_output的等级，会输出*包括这一档在内，往前所有档位*的调试信息而不是只输出这一档的调试信息
>
> - 范例：展示实体动画系统
>   1. 第一档调试信息输出展示实体的变换目标，开始动画时只输出一次
>   2. 第二档调试信息会在展示实体的动画过程中，*每刻*输出当前展示实体的动画数值，会导致刷屏所以在lv2
>
> - 使用例：
> execute if score debug_output options matches 1.. run function rhythm_axe:utilization/display_animation/utils/debug_output
> execute if score debug_output options matches 1.. run tellraw @a [{"text":"[调试.lv1]","color":"gray"},{"text":" 三角函数表已生成（3601项）","color":"green"}]

## 局部设置

如果一个谱面有自己的独占设置，那么一般会有它自己的方式存储
计分板名：谱面id.options
计分项名就是谱面的设置id
如谱面new_beginning要加一个设置easymode
那么就修改 easymode 的 new_beginning.options 分数
