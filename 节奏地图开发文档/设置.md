> 🤖 **调试等级**
>
> - 介绍
>
> 目前调试等级分两档。一档会输出不刷屏，单次执行的调试信息；第二档输出的调试信息很可能会导致刷屏。
>
> - 规范：
>   1. 所有调试信息前带`[调试.lv*]`前缀，然后可以根据要输出的信息再加前缀，如`[编辑器]`，也可以不加
>   2. 根据debug_output的等级，会输出*包括这一档在内，往前所有档位*的调试信息而不是只输出这一档的调试信息
>
> - 范例：展示实体动画系统
>   1. 第一档调试信息输出展示实体的变换目标，开始动画时只输出一次
>   2. 第二档调试信息会在展示实体的动画过程中，*每刻*输出当前展示实体的动画数值，会导致刷屏所以在lv2
>

## 设置面板

游戏内改设置的聊天栏 UI，**菜单系统页面 22**，入口 `/function rhythm_axe:options/main`。

| 操作 | 说明 |
| --- | --- |
| 打开 | `/function rhythm_axe:options/main`（无条件打开；**编辑中也能改设置**）；**谱面总表页脚的【设置】按钮**也能打开（`11703`） |
| 翻页 | 页脚【上一页】/【下一页】（4 页循环，页码显示为 `1/4`~`4/4`） |
| 收起 | 页脚【收起】；**进游戏 / 进编辑器不会自动收起**（不像谱面总表，避免打断调参） |
| 恢复默认 | 页脚【恢复默认】→ **先弹出二次确认**（警告 + 【确认恢复】/【取消】），确认后才把**所有**设置重置为初始值（含评级线、判定权重、模组开关），**不可撤销**，会全服提示 |

**四页内容**（每项的含义与默认值见上文[全局设置](#全局设置)表）

| 页 | 分类 | 内容 |
| --- | --- | --- |
| `1/4` | 游玩 | 流速、音符 hotbar 反馈、音符聊天反馈、击打挥砍动画、歌曲进度条、结算详细判定、全局击打音效组、全局击打粒子组 |
| `2/4` | 模组 | 自动模式（auto）—— 模组开关存在 `mods` 计分板，**开局时**才复制到游玩运行期。本页页脚的末位按钮变成【关闭所有模组】（其它页是【恢复默认】） |
| `3/4` | 编辑器 | 试听真实判定、试听事件播放、撤销历史上限、音乐同步偏移、多人判定延迟补偿 |
| `4/4` | 高级 | 调试等级、SS / S / A / B / C / Failed 评级线、三级判定权重、伤害扣血冷却、音乐自动对齐游戏 |

**怎么点**

- **数值项**：显示成 `[-]16[+]`，点 `[-]` / `[+]` 按步进增减。
- **开关项**：显示成 `【开】` / `【关】`，点一下切换。
- **颜色**：绿色 = 可点；**红色 = 已到边界**（点不动）。
- 页尾那个 `───────── 游玩 ─────────` 是**分类名**（提示本页是什么），不是按钮。

**不在本面板里的设置**

- **歌曲进度条的颜色**是**谱面级**设置：在编辑器「谱面设置」面板里改，编辑器预览与正式游玩共用同一个值；本面板只管「显示 / 隐藏」。

> ⚠️ 「多人判定延迟补偿」⏸ **已搁置**：设成「开」也没有效果，且每次 `/reload` 都会被强制关掉。
>
> 实现细节（文件结构、按钮值、渲染链、新增一行的流程与已知坑）见 [设置面板实现.md](设置面板实现.md)。

## 局部设置

如果一个谱面有自己的独占设置，那么一般会有它自己的方式存储。建议存在 `rhythm_axe:maps.{mapid}.options`
